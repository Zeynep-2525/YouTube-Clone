# YouTube Klonu (HTML & CSS)

**Açıklama:**  
Bu proje, temel HTML ve CSS becerilerimi geliştirmek amacıyla bir YouTube sayfasının klonunu yapmam ile ortaya çıktı. Projeyi bir eğitim videosunu takip ederek adım adım tamamladım.

**Amaç ve Öğrendiklerim:**  
- HTML yapısını ve elementlerini kullanmayı öğrenmek  
- CSS ile layout ve responsive tasarım mantığını kavramak  
- Basit bir front-end projesi oluşturup kendi düzenlemelerimi yapabilmek  

**Teknolojiler:**  
- HTML5  
- CSS3

**Not:**  
Projeyi öğrenme süreci odaklı yaptım; amacım gerçek bir YouTube klonu yapmak değil, temel web teknolojilerini pekiştirmekti.
